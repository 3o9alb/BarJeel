BARJEEL STORE PRO
=================

This is a polished, functional local e-commerce prototype for BARJEEL.

WHAT WORKS
- Luxury responsive storefront
- Product collection and category filters
- Product detail modal
- Cart
- UAE checkout form
- Shipping rules
- Discount code BARJEEL10
- Order creation
- Automatic stock reduction after checkout
- Arabic/English UI toggle
- Admin dashboard
- Edit product names, prices, stock and visibility
- Add/delete products
- Order statuses
- Store settings (shipping, free-shipping threshold, WhatsApp, email, currency)
- Local browser persistence via localStorage

IMPORTANT BEFORE REAL SALES
This prototype stores data in the browser and does NOT contain a secure server/database or real card payments.
For production:
1) Move products/orders/admin authentication to a backend/database.
2) Use secure server-side admin authentication.
3) Connect a real payment gateway (Stripe / Checkout.com / Network International / Telr etc.).
4) Configure VAT/accounting and final UAE business/legal requirements.
5) Replace placeholder product visuals with approved product photography.

EDITING
Most normal store settings can be changed from the built-in Admin dashboard.
The initial defaults are in script.js under DEFAULT_STORE.

To reset all demo data, clear the site's localStorage in your browser.
